# Import from ElectraFi

## Get the export

1. In ElectraFi, go to **Settings → Account → Advanced → Download Data**.
2. Choose **Download All**.

You'll get `.csv` or `.csv.gz` files. Both work, and you can add them all at once.

## Import it

1. In RivianMate, go to **Settings → Import Data → New import**.
2. Choose **ElectraFi** and add the files.
3. Check the preview, then import.
