# Import from Rivian Roamer

## Get the export

1. In Rivian Roamer, open **Account** from the menu by your name.
2. Go to **Data → Download a copy** and request it.
3. When it's ready, choose **Download ZIP**.

You'll get a single `.zip` file. Don't unzip it.

## Import it

1. In RivianMate, go to **Settings → Import Data → New import**.
2. Choose **Rivian Roamer** and add the `.zip`.
3. Check the preview, then import.

The copy is matched to your Rivian by VIN. It brings each charge's curve and energy breakdown, so
older sessions get the same detail as ones RivianMate recorded itself.
