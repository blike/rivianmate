# Working on the docs

This site is built with [Docusaurus](https://docusaurus.io) and lives in the repository's `website/`
folder. It's a separate npm project: it isn't part of the pnpm workspace, the app's build, or the
Docker image.

```text
website/
├── docs/               the pages, in Markdown
├── src/
│   ├── css/custom.css  theme: the app's colors, type and components
│   ├── pages/          the landing page
│   └── theme/          small overrides of Docusaurus components
├── static/img/         icons and screenshots
├── docusaurus.config.ts
└── sidebars.ts         the order of the left-hand menu
```

## Preview locally

```bash
cd website
npm ci
npm start
```

The site opens at `http://localhost:3000/` and reloads as you edit.

To check the production build, including broken links (which fail the build):

```bash
npm run build
npm run serve
```

Or `npm run preview`, which does both. Search only works on a built site: its index is generated by
`npm run build`, so under `npm start` the search box says the index is missing.

## Writing pages

- Add a Markdown file under `docs/`, and add its id to `sidebars.ts`.
- Link to other pages by relative file path, such as `[Updating](../installation/updating.md)`, so
  broken links are caught at build time.
- Write for someone setting it up for the first time: short sentences, the exact menu path in bold
  (**Settings → Notifications**), and commands they can copy.
- Screenshots come from [demo mode](./development.md#demo-mode). Never include real locations, VINs
  or tokens.
- Use admonitions (`:::tip`, `:::note`, `:::warning`, `:::danger`) sparingly.

## Theme

The site uses the same tokens as the app (`web/src/index.css`): warm near-black surfaces, hairline
borders, the yellow accent and Archivo. If the app's palette changes, update
`website/src/css/custom.css` to match.

## Deployment

`.github/workflows/docs.yml` builds the site on every pull request that touches `website/`, and on
pushes to `main` deploys it to GitHub Pages. The app's Docker workflow ignores `website/`, so a
docs-only change never builds or publishes an image.

The site is served at [rivianmate.org](https://rivianmate.org): `static/CNAME` holds the domain, and
the repository's **Settings → Pages** has it set as the custom domain, with GitHub Actions as the
source.

`rivianmate.org/discord` redirects to the Discord invite. If the invite changes, update
`DISCORD_INVITE` in `src/pages/discord.tsx`; every link on the site points at `/discord`.
